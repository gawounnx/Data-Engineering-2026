# 개발 이력과 구현 범위

문서 정리: 2026-11-21, 갱신: 2026-11-22 (FinFlow 소스 main 반영). 과거 로그와 현재 GitHub 파일을 대조한 기록입니다. 서로 다른 실행의 건수를 합쳐 하나의 최종 데이터셋으로 표현하지 않습니다.

## 전체 10단계

| 단계 | 진행 이력 | 현재 확인 한계 |
|---|---|---|
| 1. 데이터 수집 | JSONPlaceholder 20건 실습, 금융위원회 시세 300건, 한국은행 초기 용어 69건, PDF 용어 770건으로 확장, 네이버 뉴스 | 뉴스 수집기 반영(`finflow/scripts/collectors/`). 금융용어 PDF 추출·파서 미반영 |
| 2. 데이터 검증 | 건수 일치·필수 값·종가/거래량 숫자 검증, 뉴스 유효 125·오류 0 기록 | 시간 최신성·전체 결측률 미측정 |
| 3. 전처리 | 문장 분리·균형 청킹, PDF 파서와 정제 버전 개선 | 최종 파서·청킹 설정 고정 필요 |
| 4. BigQuery | 시세 300건, 금융용어 770행, 뉴스 125건·누적 183건 확인 | 현 클라우드 상태 미조회 |
| 5. 임베딩 | 128차원 모델, 페르소나 220청크 실습, 금융용어 임베딩 | 모델 비교 실험 없음 |
| 6. ChromaDB | financial_terms 컬렉션 1,121건 count 확인 | 1,122 등 다른 기록과 생성 버전 대조 필요 |
| 7. Airflow | 페르소나 DAG 실습, 뉴스 수집→검증→GCS→BigQuery→결과 확인 DAG 테스트 성공 | DAG 소스 반영. 정기 운영·장기 성공률 미검증 |
| 8. RAG | 금융용어 검색과 Gemini 답변 생성 개발, 키워드 우선 결과와 벡터 결과 기록 | 소스 반영(`finflow/src/`). 정량 검색 평가·보류 동작 미검증 |
| 9. Streamlit | 질문·답변·근거 표시 코드, 뉴스와 주가 조회 개발 | 앱 반영, 화면 상태는 AppTest로 확인. 주가 조회는 앱 미연결. 질문→답변 통합 시연 필요 |
| 10. Cloud Run | 뉴스 Job 배포, 앱 revision 배포 기록 | Dockerfile·Cloud Build 설정 반영, data COPY 실패 원인 보완. 빌드와 현재 E2E 재확인 필요 |

## 변화 과정

### 초기 수집과 ETL

기존 README에 JSONPlaceholder 20건의 수집·GCS·BigQuery 실습이 기록되어 있습니다. 금융 도메인으로 확장해 금융위원회 API의 시세 300건과 한국은행 금융용어 69건을 다뤘습니다. HTML 수집의 JS 렌더링 문제 이후 내부 JSON 응답을 분석해 requests로 전환한 이력을 남겼습니다.

### 문장·용어 단위 데이터로 확장

페르소나 20건 → 220청크 임베딩을 실습했습니다. 초기 금융용어는 69건 → 292청크로 기록되어 있으며 문장 중간이 끊기는 문제를 문장 분리·길이 균형 조정으로 개선했습니다.

후속 PDF 파싱으로 금융용어 770건과 정제 v4 파일이 등장합니다. 2026-07-26 BigQuery에서 770행을 조회했고, term 중복 조회에서 결과가 없었습니다. 이는 중복 검사 결과이며 정의의 내용 정확성을 전부 검증했다는 뜻은 아닙니다.

### 서비스 코드 분리와 화면

2026-07-26~27 기록에서 finflow 디렉터리와 config/retriever/prompt/rag, CLI, app.py가 등장합니다. 이후 src/rag.py·stock_repository.py 등 다른 경로가 나타나므로 최초 폴더 생성안과 최종 구조를 동일시하지 않습니다.

BigQuery에서 300개 종목 이름을 조회하고 BYC의 2026-07-02 데이터 1행을 조회한 결과가 있습니다. 300일치 데이터나 전체 시장 데이터라는 뜻은 아닙니다.

### 뉴스 수집 자동화

2026-08-01 기록: 10개 검색어 수집 → 중복 제거 후 기사 125건 → 검증 → GCS 보관 → BigQuery 적재. 최초 125행과 고유 article_id 125개, 재실행 신규 0건을 확인했습니다. 후속 실행에서 신규 58건과 누적 183행/고유 183개를 확인했습니다.

Airflow DAG 테스트는 단계별 성공과 최종 success가 남아 있습니다. 스케줄러가 매일 안정적으로 실행되었다는 증거와는 구분합니다.

### 컨테이너와 배포

Cloud Build 이미지 생성, Secret Manager 설정, 뉴스 Job 배포 기록이 있습니다. 앱 revision finflow-app-00004-2cn 및 finflow-app-00005-ltk의 100% traffic 배포 로그가 있습니다. 이후 data COPY 빌드가 실패한 기록도 있어 마지막 코드 변경이 배포까지 완료됐다고 표현하지 않습니다.

## 현재 저장소와 로컬 작업의 차이

2026-11-22에 로컬 `finflow/`의 최신 소스를 main에 반영했습니다(PR #2). 과거 터미널 출력을 조합해 복원하지 않고, 실제 로컬 파일을 그대로 가져왔습니다. 반영하면서 다음을 보완했습니다.
- DAG 절대 경로 제거
- 데이터 준비 상태 판단
- 스냅샷 압축 해제 보안
- 자동 테스트

현재 GitHub main에는 de-bootcamp-week1, de-bootcamp-week2, finflow와 별도 그래픽스 노트북이 있습니다. 아직 로컬에만 있는 것은 다음과 같습니다.
- week3, week4 실습
- 1주차 폴더의 금융용어 PDF 파싱·정제·청킹·임베딩·ChromaDB 적재 스크립트

다음은 의도적으로 제외했습니다.
- 비밀 값(`.env`, Airflow 키)
- Airflow 런타임
- 가상환경
- 생성 데이터(ChromaDB, 처리된 JSON)
